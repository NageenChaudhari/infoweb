Code Integrity Hash Generation Steps

Step 1: Prepare Audited Source Code

Compress the complete audited source code into a single ZIP file. This ensures integrity and consistency during hash generation. 

    used Software Putty
        
    Create zip file /var/www/html/
        
    geri_audit_code.zip

Step 2: Generate Hash Values (Linux / Ubuntu)

MD5 Hash 
    md5sum geri_audit_code.zip
SHA-1 Hash 
    sha1sum geri_audit_code.zip
SHA-256 Hash 
    sha256sum geri_audit_code.zip

Step 3: Generate Hash Values (Windows)

MD5 Hash 
    certutil -hashfile geri_audit_code.zip MD5
SHA-1 Hash 
    certutil -hashfile geri_audit_code.zip SHA1
SHA-256 Hash 
    certutil -hashfile geri_audit_code.zip SHA256

Step 4: Record Hash Values

Record the generated hash values in the audit report and ensure the same ZIP file is preserved for verification.

Important Audit Notes:
  • Always generate all hash values from the same ZIP file
  • Do not modify the source code after hash generation
  • Preserve the ZIP archive securely
  • Hash values confirm code integrity at audit time
